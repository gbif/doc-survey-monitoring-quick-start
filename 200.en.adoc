== Updating your DwC Event dataset with the Humboldt extension

****

[discrete]
===== Where does a term belong?

- DwC Event terms (preceded by ‘dwc’, e.g. term:dwc[eventID]) should be saved to the ‘Event’ table. 
- Humboldt extension terms (preceded by ‘eco’, e.g. term:eco[protocolNames]) should be saved to a separate ‘Humboldt’ table.

****

[discrete]
===== Populating terms

Each term in this document is linked with its respective term IRI alias (ex., term:eco[protocolNames]). When populating a term in the ‘event’ or ‘humboldt’ table, be sure to refer to the definition, comments, and examples provided in the linked documentation to ensure that you are following recommended usage guidelines.

****
